🎵 Cantoral Kerigma

Nuevo milagro de amor

Cantoral digital desarrollado para apoyar el servicio del ministerio de música Kerigma, facilitando el acceso a los cantos, acordes y repertorios utilizados en las celebraciones litúrgicas.

🌐 Sitio Web

https://sagradocorazondejesus.github.io/KNMA/

✨ Funciones

- 📚 Biblioteca de cantos litúrgicos.
- 🔎 Búsqueda rápida por título, letra, categoría o tiempo litúrgico.
- ⭐ Sistema de favoritos.
- 🎵 Misa de Hoy.
- ⛪ Modo presentación para la celebración.
- 🎸 Visualización de acordes sobre la letra.
- 🔁 Cambio de tonalidad.
- 🔤 Conversión entre sistema anglosajón y Do-Re-Mi.
- 👁️ Modo solo letra.
- 📄 Impresión y exportación a PDF.

📂 Categorías disponibles

- Entrada
- Kyrie
- Gloria
- Aleluya
- Ofertorio
- Santo
- Cordero
- Comunión
- Salida
- Marianos
- Otros

🎼 Objetivo

Este proyecto busca que cualquier integrante del coro pueda consultar rápidamente los cantos desde su celular, tableta o computadora, reduciendo el uso de hojas impresas y facilitando la preparación de cada celebración.
